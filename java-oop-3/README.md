# 과제명
게임 캐릭터 상속 구조

## ⚙️ 실행 방법
1. cd 명령어를 사용하여 java-oop-3/src까지 이동
2. 'javac controller/*.java model/*.java view/*.java Main.java'를 입력하여 컴파일
3. 'java.c'를 입력하여 실행

## 💡 작업 내용
- 스캐너를 사용하여 키보드로 숫자를 입력하여 원하는 캐릭터 선택
- Character 클래스 (Base) 작성
- Warrior 클래스 작성
- Mage 클래스 작성
- Controller 클래스 작성
- 캐릭터 정보를 출력하는 CharacterInfo 클래스 작성

## 🤔 느낀 점 / 어려웠던 점
- 클래스를 나누고 SOLID 원칙을 적용하여 코드를 작성하는 것이 꽤나 힘들고 노력이 필요한 것 같다.
