# 과제명
RemoteControl 인터페이스

## ⚙️ 실행 방법 
터미널 기준
1. `cd src`로 src폴더로 이동
2. `javac Main.java controller/*.java model/*.java view/*.java config/*.java` 로 컴파일
3. `java Main` 으로 실행

## 💡 작업 내용
- RemoteControl 인터페이스를 정의하고
Television, AirConditioner 클래스에서 이를 구현함
- RemoteControl[] 배열을 사용하여 여러 기기를 관리하도록 구현
- 사용자가 기기를 켤지 선택할 수 있도록 기능 추가
- 볼륨, 온도를 올리거나 내리는 기능 구현
- 현재 볼륨, 온도보다 크게 감소할 수 없도록 제한
- 잘못된 입력값에 대해 다시 입력을 받도록 처리
- MVC 패턴을 적용하여 구조 분리
