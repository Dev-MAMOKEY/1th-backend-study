# 과제명
RemoteControl 인터페이스

## ⚙️ 실행 방법
1. 터미널에서 cd java-oop-4/src를 입력하여 이동
2. javac Main.java controller/\*.java model/\*.java view/\*.java를 입력하여 컴파일
3. java Main을 입력하여 실행

## 💡 작업 내용

- RemoteControl 인터페이스 작성

- Television 클래스 작성

- AirConditioner 클래스 작성

- 배열로 장치 관리 + 반복문 실행

- 스캐너로 숫자를 입력받아 기기 컨트롤 기능

## 🤔 느낀 점 / 어려웠던 점
- 생각했던 것 보다 과제를 진행하는 시간이 많이 걸렸고 객체를 매개변수로 넘기는 것에 대해 생각해보는 계기가 되었다.
