# 과제명
Account 클래스 구현

## ⚙️ 실행 방법
터미널 창에서 과제가 들어있는 폴더로 cd 명령어로 이동 후 다음 실행

```
javac -d . controller/*.java model/*.java view/*.java Main.java
java Main
```

## 💡 작업 내용
- Account 클래스 설계
- Getter와 Setter 사용
- static 변수 - 은행 이름
- final 상수 - 최소 잔액
- 입금과 출금 기능
- 계좌 정보의 조회

## 🤔 느낀 점 / 어려웠던 점
- SOLID 원칙에 맞추어서 코드를 작성하려고 노력했지만 생각보다 시간이 많이 걸리고 생각해야 할 것들이 많았던 것 같다.
