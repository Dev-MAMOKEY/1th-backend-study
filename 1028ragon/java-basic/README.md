# 과제명
객체 배열 관리 프로그램

## ⚙️ 실행 방법
- 터미널 기준

1. 프로젝트 폴더로 이동 

   `cd java-basic`

 2. 컴파일

    `javac Student.java StudentMain.java`
    
  3. 실행

      `java StudentMain`

## 💡 작업 내용
- class, array, for loop, constructor 문법 사용해서 기능 구현
1. 학생 객체 생성
2. 배열에 저장
3. 반복문 출력 - 모든 학생 정보를 출력
