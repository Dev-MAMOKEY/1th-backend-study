# 과제명
학과 생성자 프로그램

## ⚙️ 실행 방법
1. 터미널을 이용하여 .java 파일이 위치한 폴더로 이동한다. (cd 명령어 사용)
2. javac Main.java Department.java 명령어를 사용하여 컴파일한다.
3. java Main 명령어를 이용하여 실행한다.

## 💡 작업 내용
- Department 클래스를 생성한다.
- Department 클래스의 생성자를 작성한다.
- Department 클래스 내부에 printDepartment() 멤버 함수를 작성하여 정보를 출력하게 한다.
- 여러 학과 객체 생성하여 실행 클래스를 작성한다.

## 🤔 느낀 점 / 어려웠던 점
- 코드를 좀 더 간결하게 하고 싶어서 고민하던 중 배열을 이용하여 작성하였다. Java에서의 배열에 대해서 다시 상기해보게 된 것 같다.
