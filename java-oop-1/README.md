# 과제명
학과 생성자 프로그램

## ⚙️ 실행 방법
1. 터미널에서 해당 폴더로 이동한다 :
`cd 파일경로`

2. Java 파일을 컴파일한다 :
`javac Main.java`

3. 프로그램을 실행한다 :
`java Main`
## 💡 작업 내용
- Department 클래스를 생성
- 필드(name, studentCount, building)정의
- Main 클래스에서 여러 Department 객체를 생성
- printInfo() 메서드를 구현하여 학과 정보 출력
